# Filtre Leboncoin

Extension pour Chrome, Brave et Edge qui complète les filtres natifs de Leboncoin. Elle permet d’exclure les annonces de certaines catégories, provenant de certaines villes, ou dont le titre contient des mots spécifiques.

Elle est particulièrement pertinente pour les recherches exhaustives.

## Utilisation

Via une fenêtre qui permet de renseigner les exclusions ou click droit sur une catégorie, ville ou titre d'une annonce.

## Installation

1. Téléchargez le dépôt (**Code → Download ZIP**) et décompressez-le.
2. Ouvrez `chrome://extensions` (ou `brave://extensions`, `edge://extensions`) et activez le **Mode développeur**.
3. Cliquez sur **Charger l’extension non empaquetée** et sélectionnez le dossier contenant `manifest.json`.
